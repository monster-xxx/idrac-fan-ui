# idrac-fan-ui
iDRAC Fan Control UI (Docker &amp; Synology Edition) 💡 灵感鸣谢：本项目底层 IPMI 核心逻辑参考了出色的开源项目 alombardo4/idrac-fan-control-docker。 在其基础上，我们进行了彻底的现代化重构，引入了极简的响应式 Web UI 控制台、全量传感器并发扫描、防断电持久化配置，以及针对群晖 (Synology DSM 7.x) 的原生桌面 App 深度适配。  本项目旨在为 Dell 服务器（如 R230, R720, R730 等 11G-13G 机型）提供一个工业级、可视化的散热管理解决方案，彻底告别枯燥的 SSH 命令行操作。
